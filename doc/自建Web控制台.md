# 自建 Web 控制台（配置服务器）指南

EasyTier 支持自建 Web 控制台来管理节点（对应内核的 `easytier-web` / `easytier-web-embed` 二进制，随内核一起通过【设置 → 内核下载与安装】装到 resource 目录）。EasyTier 管理器 Pro 在【Web配置 → 自建控制台】页签中提供了创建、运行、服务化和快捷入口。

> 架构参考官方文档：Web 前端与 API 后端默认共用 11211 端口，配置下发端默认 22020 端口（udp/tcp/ws）。

## 1. 新增控制台配置

1. 进入 **【Web配置】** 页，切换到 **【自建控制台】** 页签。
2. 点击 **【新增控制台配置】**，填写：
   - **配置名称**：唯一标识（如 `home`）。
   - **程序类型**：`easytier-web-embed`（内置前端，推荐）或 `easytier-web`（仅 API 后端，需自行部署前端）。
   - **API 端口 / API 监听地址**：控制台网页入口，默认 `0.0.0.0:11211`。
   - **API Host**：控制台前端回连后端的地址，默认自动生成 `http://127.0.0.1:<API端口>`。**设置错误会导致登录页验证码刷不出**；局域网/公网访问时改成实际可达地址。
   - **下发端口 / 下发协议**：供 easytier-core 连接，默认 `22020/udp`（协议可选 udp/tcp/ws；如需 wss 请自行反向代理）。
   - **高级选项**：
     - **数据库文件**：留空自动为 `resource/web-console/<配置名称>/et.db`（按配置隔离）。
     - **前端端口** `--web-server-port`、**不运行前端** `--no-web`。
     - **禁止注册** `--disable-registration`、**自动创建用户** `--allow-auto-create-user`。
     - **日志目录 / 控制台日志级别 / 文件日志级别**。
     - **自定义附加参数**：原样追加到启动命令末尾，用于 OIDC、webhook 等暂未提供独立输入框的参数。
3. 保存后列表会出现该配置。

## 2. 启动与访问

1. 点击 **【运行】**（或安装为系统服务后点【启动服务】）。
2. 状态变为 `运行中` 后，点击列表 **【控制台入口】** 列的链接（如 `http://127.0.0.1:11211`）在浏览器打开控制台。
3. 注册账户登录（注意：控制台存在内置默认账户 `admin` 与 `user`）。

## 3. 接入节点

在 **【Web配置 → 接入配置】** 页签新建配置：

- **Web启动方式** 选 **自建服务器**。
- 协议/主机/端口 与控制台的"下发端口/下发协议"一致（本机即 `udp://127.0.0.1:22020`）。
- **用户名** 填在自建控制台上注册的账户名。
- 可选填 **主机名**（Web 控制台中的显示名）与 **配置目录**（服务器不可达时回退读取该目录下的配置）。

运行后，设备即可在自建控制台中上线管理。

## 4. 系统服务化

与接入配置相同：在自建控制台列表点击 **【安装服务】**（服务名前缀 `easytierwebconsole-`），安装成功后可【启动服务】开机自启，关闭管理器后控制台仍会在后台运行。

## 5. 常见问题

- **验证码刷不出**：检查 `API Host` 是否为浏览器实际访问的后端地址。
- **端口冲突**：修改 API 端口或下发端口后重新运行。
- **找不到程序**：`easytier-web-embed` / `easytier-web` 随官方内核压缩包一起发布，请到【设置 → 内核下载与安装】重新安装内核。
- **防火墙拦截**：局域网访问请放行 API 端口（TCP）与下发端口（UDP/TCP 视协议而定）。
