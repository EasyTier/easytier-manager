# Web 管理配置指南

EasyTier 内核内置了 Web 管理功能，允许用户通过浏览器直观地监控和管理节点。EasyTier 管理器 Pro 提供了便捷的界面来配置和启动这个 Web 服务。

## 1. 什么是 Web 管理？

Web 管理是一个独立的 Web 服务，它通过 RPC 接口与 `easytier-core` 通信，并提供：

- **可视化仪表盘**: 查看当前节点的连接状态、流量、延迟等。
- **对等节点列表**: 实时展示网络中其他节点的信息。
- **配置查看**: 查看当前运行的内核配置参数。

---

## 2. 配置步骤

### 2.1 进入 Web 管理页面

在管理器的左侧菜单中，点击 **【Web 管理】**。

### 2.2 添加 Web 服务配置

1. 点击 **【新增 Web 服务配置】**。
2. 在弹出的表单中填写以下参数：
   - **配置名称**: 给这个 Web 服务起个名字（如 `local-web`）。
   - **RPC 地址**: 指向正在运行的 `easytier-core` 的 RPC 端口，默认为 `127.0.0.1:15888`。
   - **监听地址**: Web 服务运行的地址和端口，默认为 `0.0.0.0:15889`（`0.0.0.0` 表示允许通过局域网访问）。
   - **启动方式**:
     - **普通进程**: 手动点击启动，随管理器关闭而可能停止。
     - **系统服务**: 安装为系统服务，开机自启，后台运行。

![manage-step7](./assets/manage-step7.png)

### 2.3 启动 Web 服务

1. 在列表中找到刚刚创建的配置。
2. 点击 **【启动】**。
3. 状态显示为 `运行中` 后，点击 **【打开管理界面】** 按钮。

---

## 3. 访问 Web 界面

启动成功后，你可以通过以下方式访问：

- **本地访问**: 在浏览器输入 `http://localhost:15889`。
- **局域网访问**: 在同局域网的其他设备输入 `http://当前设备IP:15889`。
- **虚拟网访问**: 在组网内的其他设备输入 `http://当前设备的虚拟IP:15889`。

---

## 4. 系统服务化

如果你希望 Web 管理后台一直在线，建议将其安装为系统服务：

1. 在 Web 管理列表中，找到对应的配置。
2. 点击 **【安装服务】**。
3. 安装成功后，点击 **【启动服务】**。
4. 此时，即使你关闭了管理器，Web 管理后台依然会在后台运行。

![manage-step8](./assets/manage-step8.png)

---

## 5. 常见问题

- **无法连接到 RPC**: 确保 `easytier-core` 已经启动，且其配置中的 RPC 端口与 Web 配置中的 RPC 地址一致。
- **端口冲突**: 如果 15889 端口被占用，请在配置中修改 **监听地址** 为其他端口（如 `0.0.0.0:15890`）。
- **防火墙拦截**: 如果无法通过局域网访问，请检查物理机的防火墙是否允许该端口的入站流量。
