# 快速组网指南

本指南将帮助你从零开始，使用 EasyTier 管理器 Pro 快速搭建一个虚拟局域网。

## 准备工作

1. 确保已根据 [内核安装指南](./内核安装.md) 安装好 `easytier-core`。
2. 准备至少两台需要组网的设备（可以是 Windows、Linux 或 macOS）。

---

## 步骤 1：创建组网配置

1. 打开管理器，进入 **【配置】** 页面。
2. 点击 **【新增组网配置(表单)】**。
3. 填写基本参数：
   - **虚拟网 IP**: 为当前设备分配一个虚拟 IP（例如 `10.10.10.1`）。每台设备的虚拟 IP 必须唯一且在同一网段。
   - **网络名称**: 设置一个组网标识（如 `my_home_net`）。所有要组网的设备必须使用**相同**的网络名称。
   - **网络密码**: 设置一个安全密码。所有设备必须使用**相同**的网络密码。
4. （可选）如果你有公网服务器，可以在 **【公网对方节点】** 中填写服务器地址（如 `tcp://x.x.x.x:11010`），作为打洞辅助。
5. 点击 **【保存】**。

---

## 步骤 2：在其他设备上重复操作

1. 在第二台设备上安装管理器和内核。
2. 创建配置：
   - **虚拟网 IP**: 设置为 `10.10.10.2`（不同于第一台）。
   - **网络名称**: `my_home_net`（与第一台一致）。
   - **网络密码**: `你的密码`（与第一台一致）。
3. 保存配置。

---

## 步骤 3：启动组网

1. 返回两台设备的 **【工作台】**（首页）。
2. 在配置列表中找到刚刚创建的配置。
3. 点击 **【启动】** 按钮。
4. 观察下方的日志输出，当看到 `New peer joined` 或类似连接成功的提示时，表示组网成功。

---

## 步骤 4：验证连接

1. 在第一台设备（`10.10.10.1`）上，尝试 ping 第二台设备的虚拟 IP：
   ```bash
   ping 10.10.10.2
   ```
2. 如果能 ping 通，说明你们已经处于同一个虚拟局域网中，可以直接通过虚拟 IP 进行文件共享、远程桌面或游戏联机。

---

## 进阶技巧

- **系统服务**: 如果希望开机后自动后台组网，可以在 **【配置】** 页面点击 **【安装服务】**。
- **P2P 优先**: EasyTier 会优先尝试 P2P 直连。如果 P2P 失败，会自动通过中继服务器转发，确保连接始终可用。
