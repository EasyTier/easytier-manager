# 服务端配置指南

如果你拥有一台具有公网 IP 的服务器，可以将其配置为 EasyTier 的公网节点（或中继节点），以大幅提升打洞成功率和组网稳定性。

## 1. 为什么需要服务端？

虽然 EasyTier 支持纯 P2P 组网，但在复杂的对称型 NAT 环境下，直接 P2P 可能会失败。此时：

- **打洞辅助**: 公网服务器可以作为“对等节点”帮助内网设备发现彼此。
- **流量中继**: 当 P2P 彻底无法建立时，流量将通过服务器中继，确保连接不中断。

---

## 2. 服务端部署（Linux 示例）

### 2.1 获取内核

在服务器上下载对应的 EasyTier 内核：

```bash
wget https://github.com/EasyTier/EasyTier/releases/download/v2.2.4/easytier-x86_64-unknown-linux-gnu.tar.gz
tar -zxvf easytier-x86_64-unknown-linux-gnu.tar.gz
```

### 2.2 运行公网节点

服务端通常不需要虚拟网 IP，只需作为公网接入点运行：

```bash
./easytier-core --network-name "my_home_net" --network-secret "你的密码" --listeners "tcp://0.0.0.0:11010" --listeners "udp://0.0.0.0:11010"
```

- `--listeners`: 监听 11010 端口（TCP 和 UDP），这是客户端连接的入口。

---

## 3. 防火墙配置

请务必在服务器的安全组/防火墙中开放以下端口：

- **TCP 11010**: 用于握手和中继。
- **UDP 11010**: 用于 P2P 打洞辅助和数据传输。

---

## 4. 客户端连接

在 EasyTier 管理器 Pro 的配置中：

1. 找到 **【公网对方节点】** 选项。
2. 填写服务器的地址：`tcp://你的服务器公网IP:11010`。
3. 确保客户端的 **网络名称** 和 **网络密码** 与服务器完全一致。

---

## 5. 进阶：服务端作为子网网关

如果你希望通过服务器访问其所在的内网环境，可以在服务端配置中开启 **【子网代理】**：

- **子网**: `192.168.1.0/24`
- 这样，组网内的其他成员就可以通过虚拟 IP 直接访问服务器所在局域网的设备。
