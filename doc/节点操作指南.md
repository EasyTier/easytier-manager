# 节点操作指南

本指南详细介绍了在 EasyTier 管理器 Pro 中如何管理和操作网络中的节点。

## 1. 查看节点状态

启动组网配置后，首页（工作台）的表格会实时显示当前网络中的节点信息：

- **虚拟 IP**: 节点在虚拟网络中的地址。
- **主机名**: 节点的设备名称。
- **物理地址**: 节点的实际公网或内网 IP。
- **连接类型**:
  - `P2P`: 节点间直接通信，延迟最低。
  - `Relay`: 通过中继服务器转发，延迟相对较高。
- **NAT 类型**: 显示当前节点的 NAT 环境（如 FullCone, Restricted 等），影响 P2P 成功率。
- **流量统计**: 实时显示与该节点之间的上传和下载流量。

---

## 2. 节点管理操作

### 2.1 刷新列表

列表会根据设置的频率自动刷新，你也可以手动点击刷新按钮立即获取最新状态。

### 2.2 复制信息

右键点击节点行，可以快速复制该节点的虚拟 IP 或物理地址。

---

## 3. 常见连接问题排查

### 3.1 无法发现节点

- **网络名称/密码不一致**: 确保所有节点的 `Network Name` 和 `Network Secret` 完全相同。
- **防火墙限制**: 检查物理机防火墙是否允许 UDP 流量通过。
- **公网节点不可达**: 检查配置中的公网辅助节点是否在线且端口开放。

### 3.2 始终显示为 Relay（中继）

- **NAT 限制**: 如果双方都是对称型 NAT（Symmetric NAT），则无法建立 P2P。
- **尝试打洞**: 确保双方都配置了相同的公网辅助节点，这有助于 NAT 穿透。

---

## 4. 进阶：子网路由管理

如果你在配置中开启了“子网代理”，该节点将作为网关，允许网络中的其他节点访问其背后的局域网设备。

- 确保子网掩码配置正确（如 `192.168.1.0/24`）。
- 其他节点无需额外配置即可通过虚拟 IP 段访问该子网。
