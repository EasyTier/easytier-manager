# 内核安装指南

EasyTier 管理器 Pro 需要 EasyTier 核心内核（`easytier-core`）才能执行组网操作。本指南将介绍如何通过管理器自动安装或手动安装内核。

## 1. 自动安装（推荐）

管理器内置了一键下载和安装功能，支持从 GitHub 或多个国内加速镜像源获取内核。

### 操作步骤：

1. 打开管理器，进入 **【设置】** 页面。
2. 在 **【内核下载】** 区域，点击版本下拉框选择需要的版本（建议选择最新稳定版）。
3. 如果国内下载缓慢，可以在 **【下载镜像源】** 中切换不同的加速地址。
4. 点击 **【开始下载】**。
5. 下载完成后，点击 **【安装内核】**。
6. 点击 **【检测内核是否存在】** 确认安装成功。

---

## 2. 手动安装

如果你无法通过管理器自动下载，也可以手动放置内核文件。

### 操作步骤：

1. 访问 [EasyTier 官方 GitHub Release](https://github.com/EasyTier/EasyTier/releases) 下载对应系统的压缩包。
   - **Windows**: 下载 `easytier-x86_64-pc-windows-msvc.zip`
   - **Linux**: 下载 `easytier-x86_64-unknown-linux-gnu.tar.gz`
2. 解压获取 `easytier-core`（Windows 下为 `easytier-core.exe`）和 `easytier-cli`（可选）。
3. 在管理器 **【设置】** 页点击 **【打开内核目录】**。
4. 将解压出的内核文件放入该目录中。
   - 默认目录通常位于：`程序根目录/resources/bin/` 或用户数据目录下的 `easytier-core`。
5. 返回管理器点击 **【检测内核是否存在】**。

---

## 3. 常见问题

- **权限问题**: 在 Linux 或 macOS 上，如果手动放置内核，请确保文件具有可执行权限：
  ```bash
  chmod +x easytier-core
  ```
- **版本不匹配**: 如果你使用了非常旧的内核版本，部分新特性（如 Web 管理）可能无法正常工作。建议始终保持内核版本与管理器版本同步更新。
- **杀毒软件拦截**: Windows 下 `easytier-core.exe` 可能会被杀毒软件拦截，请将其添加到白名单。
