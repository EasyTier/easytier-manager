# 界面介绍

EasyTier 管理器 Pro 采用了现代化的响应式界面设计，主要分为以下几个核心功能模块。

## 1. 工作台（首页）

工作台是管理器的核心操作区，用于控制组网任务的生命周期。

- **配置切换**: 顶部下拉菜单可快速切换不同的组网配置文件。
- **状态面板**: 实时显示当前内核的运行状态（运行中/已停止）、PID、启动时间等。
- **控制按钮**:
  - **启动/停止**: 一键开关组网任务。
  - **重启**: 重新加载当前配置并重启内核。
- **节点列表**: 显示当前网络中的所有对等节点（Peers），包含其虚拟 IP、物理地址、连接方式（P2P 或中继）、延迟、上传/下载流量等详细信息。
- **实时日志**: 底部区域实时输出内核运行日志，方便排查连接问题。

## 2. 配置页

用于管理所有的组网配置文件。

- **配置列表**: 展示已创建的 `.toml` 配置文件，支持一键启动、安装为系统服务或删除。
- **新增配置**:
  - **表单模式**: 适合初学者，提供直观的输入框、开关和下拉菜单，涵盖了虚拟网 IP、网络名、密码、公网节点、代理设置等常用参数。
  - **编辑器模式**: 适合进阶用户，直接通过代码编辑器（Monaco Editor）编辑 TOML 格式的原始配置文件。
- **系统服务管理**: 支持将选中的配置安装为系统服务，实现开机自动后台运行。

## 3. Web 管理页

支持管理远程或本地的 Web 管理接口。

- **Web 节点列表**: 存储并管理多个 Web 管理地址。
- **远程监控**: 通过 Web 接口直接查看远程设备的组网状态。

## 4. 统计页

提供可视化的数据展示（需内核支持）。

- **流量统计**: 以图表形式展示网络的实时上传和下载速率。
- **网络拓扑**: 直观展示当前节点与其他节点的连接关系。

## 5. 设置页

管理器的全局环境配置。

- **内核管理**: 包含内核检测、一键下载、加速源切换、安装内核等功能。
- **路径配置**: 查看并复制内核目录、配置目录、日志目录等，支持一键打开对应的文件夹。
- **系统设置**:
  - 语言切换（中/英）。
  - 管理器日志级别设置。
  - 软件版本检测与更新。
- **个性化**: 支持主题切换、界面布局调整等。
